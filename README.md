# App Collecte DCN

Application de collecte de données DCN (Direction des Comptes Nationaux).

## Description

Cette application permet la collecte, la gestion et le traitement des données DCN.

## Structure du projet

```
app_collecte_dcn/
├── backend/        # API et logique serveur
├── frontend/       # Interface utilisateur
├── database/       # Scripts et migrations SQL
├── docs/           # Documentation
└── scripts/        # Scripts utilitaires
```

## Installation

```bash
# Cloner le dépôt
git clone https://github.com/abdouldevelop/app_collecte_dcn.git
cd app_collecte_dcn
```

## Technologies

- Backend : Node.js / Express (ou selon stack choisie)
- Frontend : React / HTML/CSS
- Base de données : MySQL / PostgreSQL
